💳 Credit Card Financial Dashboard

An interactive Credit Card Financial Dashboard built using Power BI to analyze credit card transactions, customer spending patterns, revenue, and overall financial performance.

📊 Project Overview

This project transforms credit card transaction data into meaningful business insights through interactive visualizations and KPIs. The dashboard helps analyze customer behavior, transaction trends, revenue performance, and spending patterns across different categories.

🔍 Key Insights & Analysis

💰 Revenue & Transaction Analysis – Track total revenue, transaction amount, transaction count, and customer metrics.

📈 Time-Based Analysis – Analyze weekly and monthly revenue and transaction trends.

👥 Customer Analysis – Understand spending patterns based on gender, age group, income, education, and occupation.

💳 Card Analysis – Compare performance across different credit card categories.

🛍️ Expenditure Analysis – Identify spending patterns across various expenditure categories.

📱 Transaction Analysis – Analyze different transaction methods and customer preferences.

🎯 Interactive Filtering – Use slicers and filters to explore data dynamically.


🛠️ Tools & Technologies

Power BI

📌 Dashboard Features

Interactive KPI cards
Revenue and transaction trend charts
Customer segmentation
Card category analysis
Expenditure category analysis
Interactive slicers and filters
Business-focused visualizations


🎯 Objective

The main objective of this project is to demonstrate how Power BI and DAX can be used to transform financial transaction data into actionable business insights and support data-driven decision-making.
